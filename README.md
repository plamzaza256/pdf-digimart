# PDF ให้แม่มึงทำ — ร้านขายไฟล์ดิจิทัล (รุ่นทดลอง v1)

เว็บไซต์ร้านขายไฟล์ PDF ภาษาไทย เน้นขายหนังสือ เอกสาร และข้อสอบ
สร้างด้วย **React + TypeScript + Vite** รองรับมือถือและคอมพิวเตอร์ ใช้งบ **0 บาท**

> ⚠️ **ประกาศสำคัญ (โปรดอ่าน):**
> - เว็บนี้เป็น **ระบบจำลองเพื่อทดลองหน้าตาและขั้นตอน** เท่านั้น
> - **ยังไม่มีการชำระเงินจริง** กดสั่งซื้อจะได้แค่ “คำสั่งซื้อจำลอง”
> - **ระบบสมาชิกยังไม่ปลอดภัยจริง** เก็บใน localStorage ของเบราว์เซอร์ ห้ามใช้รหัสผ่านจริง
> - **ยังไม่เปิดดาวน์โหลดไฟล์ PDF ฉบับเต็ม** และไม่มีไฟล์ส่วนตัวใน `public/`

## หน้าที่มีในรุ่นแรก

- `/` หน้าแรก — จุดเด่น + สินค้าแนะนำ + ขายดี
- `/shop` หน้าร้าน — รายการ PDF + ค้นหา + กรองหมวด + เรียงราคา
- `/product/:id` รายละเอียดสินค้า — เพิ่มลงตะกร้า / ซื้อเลย (จำลอง)
- `/cart` ตะกร้าสินค้า
- `/login` + `/register` เข้าสู่ระบบ/สมัครสมาชิก (จำลอง เก็บในเครื่อง)
- `/orders` คำสั่งซื้อของฉัน (ต้องล็อกอินจำลองก่อน)
- `/admin` แอดมินจัดการสินค้า — เพิ่ม/แก้ไข/ลบ/รีเซ็ตข้อมูลตัวอย่าง
  - ทดลองเข้าเร็ว: ปุ่ม “ทดลองเข้าเป็นแอดมิน” ในหน้า login หรือสมัครด้วย `admin@example.com`

## โครงสร้างโปรเจกต์

```
src/
  types.ts            # ชนิดข้อมูลกลาง (เตรียมต่อ DB จริง)
  data/products.ts    # ข้อมูลสินค้าจำลอง 8 รายการ
  store/auth.tsx      # ระบบสมาชิกจำลอง (localStorage)
  store/shop.tsx      # สินค้า + ตะกร้า + ออเดอร์จำลอง + CRUD แอดมิน
  components/         # Navbar, Footer, ProductCard
  pages/              # Home, Shop, ProductDetail, Login, Register, Cart, Orders, Admin
  App.tsx             # เส้นทาง (HashRouter เพื่อเปิดไฟล์ build ตรง ๆ ได้)
  index.css           # สไตล์ทั้งหมด ไม่พึ่ง CSS framework
```

แยกชั้น `data` / `store` / `pages` ไว้แล้ว อนาคตเปลี่ยน `store/*` ไปเรียก API/ฐานข้อมูลจริงได้โดยไม่ต้องรื้อหน้าเว็บ

## วิธีติดตั้งและเปิดใช้งาน (งบ 0 บาท)

ต้องมี Node.js 18 ขึ้นไป (แนะนำ 20)

```bash
# 1. เข้าโฟลเดอร์โปรเจกต์
cd "สร้างเว็ปไซต์ขายของ"

# 2. ติดตั้งไลบรารี (ครั้งแรกครั้งเดียว)
npm install

# 3. เปิดเซิร์ฟเวอร์พัฒนา
npm run dev
# เปิดเบราว์เซอร์ไปที่ http://localhost:5173
```

## วิธีสร้างไฟล์สำหรับใช้งานจริง (deploy ฟรี)

```bash
npm run build
```

จะได้โฟลเดอร์ `dist/` เอาไปวางบนโฮสต์ฟรีได้เลย เช่น:

- **Cloudflare Pages / Netlify / Vercel (แผนฟรี):** ลากโฟลเดอร์ `dist` ไปวาง หรือเชื่อม GitHub แล้วตั้ง build command `npm run build`, output `dist`
- โปรเจกต์ใช้ `HashRouter` แล้ว จึงเปิดผ่านไฟล์ static ได้โดยไม่ต้องตั้งค่า rewrite ฝั่งเซิร์ฟเวอร์

ตรวจก่อนส่งงาน:

```bash
npm run build
```

## ไลบรารีที่ใช้ (น้อยที่สุด)

- `react`, `react-dom` — หน้าจอ
- `react-router-dom` — เส้นทางระหว่างหน้า
- ไม่ใช้ UI framework / ไม่ใช้บริการเสียเงิน

## งานที่ยังไม่ทำ (รอบถัดไปเมื่อพร้อมเป็นร้านจริง)

1. ฐานข้อมูลจริง (เช่น Supabase/Firebase แผนฟรี) + API สินค้า/ออเดอร์
2. ระบบสมาชิกจริง + เข้ารหัส + ลืมรหัสผ่าน
3. ชำระเงินจริง (PromptPay / บัตร / TrueMoney) ผ่านผู้ให้บริการ
4. เก็บไฟล์ PDF จริงในที่ปลอดภัย + สร้างลิงก์ดาวน์โหลดชั่วคราวหลังจ่ายเงิน
5. ระบบแอดมินอัปโหลดไฟล์ + แดชบอร์ดยอดขาย
6. กฎหมาย: เงื่อนไขใช้บริการ + นโยบายคืนเงิน + PDPA
